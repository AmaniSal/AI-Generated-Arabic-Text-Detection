# AI-Generated Arabic Text Detection

This repository is for the MSIS-822 course project. The main goal of the project is to detect AI-generated Arabic text using data mining and machine learning techniques.

## Dataset
The dataset used in this project is the Arabic Generated Abstracts dataset from Hugging Face.

It contains three splits based on the text generation method:
- `by_polishing`: 2,851 samples
- `from_title`: 2,963 samples
- `from_title_and_content`: 2,574 samples

Each sample contains one original human-written abstract and four AI-generated abstracts generated by:
- ALLAM
- JAIS
- LLaMA
- OpenAI

- Checked the dataset splits, columns, and data types.
- Checked for missing values.
- Checked for duplicate rows.
- Checked for empty text values.
- Examined the distribution of Human and AI-generated text.

## Initial Findings
The dataset contains 8,388 original human-written abstracts.

After considering the four AI-generated versions for each original abstract:
- Human-written texts: 8,388
- AI-generated texts: 33,552
- Total text instances: 41,940

The class distribution is:
- Human: 20%
- AI-generated: 80%

No missing values, empty text values, or fully duplicated rows were found in the three dataset splits.
